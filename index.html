ระบบต้นแบบตรวจจับและแจ้งเตือนท่านั่ง SPYNE

โครงงาน SPYNE มีวัตถุประสงค์เพื่อพัฒนาระบบต้นแบบสำหรับตรวจจับและจำแนกท่านั่งขณะใช้งานคอมพิวเตอร์ และแจ้งเตือนเมื่อผู้ใช้คงท่าที่ควรปรับต่อเนื่อง โดยใช้บอร์ด Arduino UNO R4 WiFi ร่วมกับเซนเซอร์อัลตราโซนิก HC-SR04 จำนวน 2 ตัว ติดตั้งบริเวณหน้าจอที่ระดับศีรษะและหน้าอก ระบบเปรียบเทียบระยะที่วัดได้กับค่าอ้างอิงจากการปรับเทียบในท่านั่งตรง และใช้ค่าคลาดเคลื่อนที่กำหนดเพื่อจำแนกสถานะ โดยไม่ใช้ภาพจากกล้อง

โปรแกรมปัจจุบันจำแนกสถานะเป็นนั่งตรง ใกล้เกินไป ไกลเกินไป คอยื่น ตัวไถลหรือหลังยุบ ไม่ได้นั่ง และสถานะไม่สมดุลสำหรับกรณีที่ไม่ตรงเงื่อนไขหลัก การอ่านระยะใช้ค่าเฉลี่ยจากตัวอย่างที่รับสัญญาณได้ และยืนยันท่าใหม่เมื่อพบต่อเนื่อง 4 รอบ ระบบแสดงระยะและสถานะบนจอ LCD 16×2 ผ่าน I2C พร้อมแจ้งสถานะด้วย RGB LED เมื่อท่าที่ควรปรับคงอยู่ครบ 10 วินาทีตามเวลาที่ตั้งไว้ จะใช้ไฟสีแดงและเสียง Buzzer นอกจากนี้ยังเชื่อมต่อ Arduino Cloud เพื่อส่งค่าระยะและสถานะ รับค่าคลาดเคลื่อน และรับคำสั่งปรับเทียบ

โครงงานอยู่ระหว่างพัฒนาและทดสอบ โค้ดยังไม่ใช่ฉบับสุดท้าย และยังไม่มีผลการทดลองจริงเพื่อสรุปความแม่นยำหรือประสิทธิภาพในการใช้งาน เนื้อหาที่นำเสนอจึงอธิบายการออกแบบและพฤติกรรมตามโปรแกรมต้นแบบ โดยเว้นพื้นที่สำหรับทีมผู้จัดทำเพิ่มภาพชิ้นงาน วิดีโอการทดลอง และผลประเมินภายหลัง

คำสำคัญ: ท่านั่ง · อัลตราโซนิก · Arduino UNO R4 WiFi · Arduino Cloud · Physical Computing

อ่านบทคัดย่อภาษาอังกฤษ / English abstract

SPYNE is an educational prototype designed to detect sitting posture during computer use and provide feedback when a posture requiring adjustment persists. The system uses an Arduino UNO R4 WiFi and two HC-SR04 ultrasonic sensors positioned at head and chest levels near the monitor. Measured distances are compared with calibrated upright baselines and a configurable tolerance, without using a camera.

The current program classifies upright, too close, too far, head forward, slide/slump, and not sitting states, with an additional unbalanced state for unmatched patterns. Valid distance readings are averaged, and a new state must persist for four sensing cycles before being accepted. A 16×2 I2C LCD displays distances and posture. An RGB LED provides visual feedback, while a buzzer is activated after a sustained non-upright, seated state reaches the configured 10-second delay. Arduino Cloud exchanges distance and posture data and supports remote tolerance adjustment and calibration requests.

Development and physical testing are ongoing. The code is not final, and no experimental results are yet available to establish classification accuracy or practical effectiveness. This presentation describes the prototype design and current implementation; photographs, demonstration videos, and evaluation results will be supplied by the project team.

Keywords: sitting posture, ultrasonic sensing, Arduino UNO R4 WiFi, Arduino Cloud, physical computing.

ตารางนี้แสดงขาสัญญาณจากโปรแกรม ส่วนการต่อไฟเลี้ยง ขาร่วมของ LED และค่าตัวต้านทานต้องอ้างอิงวงจรจริงของทีม

การอ่านระยะและการปรับเทียบ

  1. เริ่มระบบ: ตั้งค่าขาและ LCD แล้วเชื่อมต่อ Arduino Cloud ระหว่างรอเชื่อมต่อไฟสีน้ำเงินจะกะพริบ โปรแกรมจะเข้าสู่ loop หลังเชื่อมต่อสำเร็จ
  2. อ่านระยะ: ส่งพัลส์ Trig ยาว 10 µs แล้วใช้ pulseIn() อ่าน Echo โดยกำหนด timeout 25,000 µs คำนวณระยะเป็น pulseWidth × 0.0343 ÷ 2 และเก็บเป็นจำนวนเต็มหน่วยเซนติเมตร
  3. กรองค่า: อ่านเซนเซอร์ละ 3 ครั้ง เฉลี่ยเฉพาะค่าที่ต่ำกว่า 350 หากไม่มีค่าที่ใช้ได้จะคืน 350 เป็นค่าสัญญาณขาดหาย เริ่มอ่านรอบถัดไปเมื่อเวลาที่ผ่านไปถึงเกณฑ์ 250 ms; รอบจริงขึ้นอยู่กับเวลาที่ใช้วัดและ delay ด้วย
  4. Calibration: เมื่อ calibrateTrigger เป็น true ระบบนับถอยหลัง 3 วินาที ให้ผู้ใช้นั่งตรง แล้วอ่าน 10 ตัวอย่างต่อเซนเซอร์เพื่อหาค่าเฉลี่ยเป็น baseline ใหม่ จากนั้นตั้ง trigger กลับเป็น false
  5. จำแนก: เปรียบเทียบกับ baseline โดยใช้ toleranceDistance ถ้าค่ามากกว่า 0 มิฉะนั้นใช้ 6 cm ค่าตั้งต้นก่อน Calibration คือศีรษะ 55 cm และหน้าอก 60 cm

เงื่อนไขจำแนกท่านั่ง

ตรวจตามลำดับในตาราง “ปกติ” คือระยะต่างจาก baseline ไม่เกิน tolerance; “ใกล้” และ “ไกล” คืออยู่นอกช่วงดังกล่าว

สถานะเงื่อนไขใน computeState()
NOT SITTINGระยะทั้งสองมากกว่า baseline ของตัวเอง + 50 cm
UPRIGHTศีรษะปกติ และหน้าอกปกติ
TOO CLOSEศีรษะใกล้ และหน้าอกใกล้
TOO FARศีรษะไกล และหน้าอกไกล
HEAD FORWARDศีรษะใกล้ แต่หน้าอกปกติ
SLIDE / SLUMPหน้าอกไกล และศีรษะปกติหรือใกล้
UNBALANCEDไม่ตรงกับเงื่อนไขข้างต้น

ก่อนเปลี่ยนสถานะ ระบบต้องตรวจพบท่าใหม่เดียวกันต่อเนื่อง 4 รอบ เพื่อลดการเปลี่ยนสถานะจากค่าที่แกว่งชั่วคราว

การแสดงผลและแจ้งเตือน

  • LCD: แถวแรกแสดง H และ C เป็นระยะศีรษะ/หน้าอก แถวที่สองแสดงชื่อสถานะ
  • นั่งตรง: ไฟเขียว และยกเลิกการนับเวลาท่าที่ควรปรับ
  • ไม่ได้นั่ง: ไฟน้ำเงิน และยกเลิกการนับเวลาท่าที่ควรปรับ
  • สถานะอื่น: ไฟเหลืองในช่วงก่อนครบ 10 วินาที จากนั้นเป็นไฟแดงและเสียงความถี่ 1,000 Hz ยาว 50 ms โดยให้เสียงได้เมื่อผ่านไปอย่างน้อย 1 วินาทีจากเสียงเตือนครั้งก่อน

สถานะการพัฒนาและข้อจำกัดของโค้ดปัจจุบัน
  • ยังไม่มีผลทดลองจริงสำหรับรายงานความแม่นยำและเวลาตอบสนอง
  • เงื่อนไข SLIDE / SLUMP ในโปรแกรมต่างจากตาราง README เดิม หน้านี้ยึด SPYNE.ino ที่แนบ
  • ระหว่าง Calibration ใช้ค่าที่อ่านโดยตรง 10 ครั้ง รวมถึงค่า timeout หากเกิดขึ้น ยังไม่ได้กรองแบบ readFiltered()
  • baseline เก็บในตัวแปรหน่วยความจำ เมื่อรีสตาร์ตจะกลับเป็นค่าตั้งต้นในโค้ด
  • ช่วง setup รอจนเชื่อมต่อ Cloud สำเร็จ จึงยังไม่เข้าสู่การวัดปกติหากเชื่อมต่อไม่ได้
  • หากเปลี่ยนจากท่าที่ควรปรับท่าหนึ่งไปอีกท่าหนึ่ง เวลาการเตือนยังนับต่อจนกลับเป็น UPRIGHT หรือ NOT SITTING

SPYNE.ino — ดูโค้ดทั้งหมด
Arduino / C++ · 308 บรรทัด 
#include "thingProperties.h"
#include <LiquidCrystal_I2C.h>

// ultrasonic sensor
const int HEAD_TRIG = 2;
const int HEAD_ECHO = 3;
const int CHEST_TRIG = 4;
const int CHEST_ECHO = 5;
const int NO_ECHO = 350;

// passive buzzer
const int BUZZER_PIN = 6;
const int TONE = 1000; // change tone

// RGB LED
const int LED_R = 9;
const int LED_G = 10;
const int LED_B = 11;

// liquid crystal
LiquidCrystal_I2C lcd(0x27, 16, 2);

// local variable
const int SENSOR_INTERVAL  = 250;
const int CLOUD_INTERVAL   = 3000; // 3 seconds
const int ALERT_DELAY      = 10000; // wrong position more than this will triggered
const int OUT_FRAME_MARGIN = 50;
const int STATE_CONFIRM    = 4; // need to hold 4 sensor cycles

int local_head_distance;
int local_chest_distance;
int head_base_line  = 55; // default can changed
int chest_base_line = 60; // default can changed

bool calibrateRequested = false;

String candidateState = "";
int candidateCount = 0;

// time control variable
unsigned long now;
unsigned long previousRead;
unsigned long lastCloudSync;
unsigned long badPostureStartTime = 0;
bool isBadPosture = false;

void setup()
{
  Serial.begin(9600);
  delay(1500); // delay gives the chance to wait for a Serial Monitor

  pinMode(HEAD_TRIG,  OUTPUT);
  pinMode(HEAD_ECHO,  INPUT);
  pinMode(CHEST_TRIG, OUTPUT);
  pinMode(CHEST_ECHO, INPUT);

  pinMode(LED_R, OUTPUT);
  pinMode(LED_G, OUTPUT);
  pinMode(LED_B, OUTPUT);

  // no pin setup need for passive buzzer

  lcd.init();
  lcd.backlight();
  lcd.print("SPYNE Starting..");

  // Connecting to Arduino IOT Cloud
  initProperties();
  ArduinoCloud.begin(ArduinoIoTPreferredConnection);
  setDebugMessageLevel(2);
  ArduinoCloud.printDebugInfo();

  while (ArduinoCloud.connected() == 0) { // blink Blue while not connected
    ArduinoCloud.update(); // Keep background connection
    setColor(0, 0, 255); // Blink Blue
    delay(300);
    setColor(0, 0, 0);
    delay(300);
    Serial.print(".");
  }
  
  setColor(0, 255, 0);
  lcd.clear();
  postureState = "NOT SITTING";
  lcd.print("Connected!");
  delay(1000);
  lcd.clear();
}

// +-----------+
// | MAIN LOOP |
// +-----------+
void loop()
{
  ArduinoCloud.update();

  if (calibrateRequested) { // calibration
    calibrateRequested = false;
    runCalibration();
    calibrateTrigger = false;
  }

  now = millis();
  // read from sensor
  if (now - previousRead >= SENSOR_INTERVAL) {
    previousRead = now;
    local_head_distance = readFiltered(HEAD_TRIG, HEAD_ECHO);
    delay(30);
    local_chest_distance = readFiltered(CHEST_TRIG, CHEST_ECHO);

    classifyPosture();

    displayLocalFeedback();
  }

  // sync distance to cloud
  if (now - lastCloudSync >= CLOUD_INTERVAL) {
    lastCloudSync = now;
    headDistance = local_head_distance;
    chestDistance = local_chest_distance;
  }
}

void setColor(int r, int g, int b) {
  analogWrite(LED_R, r);
  analogWrite(LED_G, g);
  analogWrite(LED_B, b);
}

int readUltrasonicSensor(int trig, int echo) {
  digitalWrite(trig, LOW);
  delayMicroseconds(10);
  digitalWrite(trig, HIGH);
  delayMicroseconds(10);
  digitalWrite(trig, LOW);

  long pulseWidth = pulseIn(echo, HIGH, 25000); // timeout 25ms
  if (pulseWidth == 0) { // timeout
    return NO_ECHO;
  }
  return pulseWidth*0.0343/2.0;
}

int readFiltered(int trig, int echo) {
  int sum = 0;
  int count = 0;
  for (int i=0; i<3; i++) {
    int d = readUltrasonicSensor(trig, echo);
    if (d < NO_ECHO) { // ignore timeout
      sum += d;
      count++;
    }
    delay(15);
  }
  if (count == 0) return NO_ECHO;   // all 3 timed out
  return sum / count;
}

void runCalibration() {
  // count down 3 seconds and set head_base_line and chest_base_line
  int SAMPLES = 10;
  lcd.clear();
  lcd.setCursor(0,0);
  lcd.print("Sit Upright!");
  lcd.setCursor(0,1);
  lcd.print("Calibrate in: ");
  for (int i=3; i>0; i--) {
    ArduinoCloud.update(); // Keep background connection
    lcd.setCursor(14,1);
    lcd.print(i);
    setColor(0, 255, 255);
    tone(BUZZER_PIN, 400, 300); // change count down tone
    delay(300);
    setColor(0, 0, 0);
    delay(700);
  }
  tone(BUZZER_PIN, TONE, 100);

  long sumH = 0, sumC = 0;
  for (int s=0; s<SAMPLES; s++) {
    sumH += readUltrasonicSensor(HEAD_TRIG, HEAD_ECHO);
    delay(35);
    sumC += readUltrasonicSensor(CHEST_TRIG, CHEST_ECHO);
    delay(35);
  }

  head_base_line  = sumH / SAMPLES;
  chest_base_line = sumC / SAMPLES;

  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Saved Baseline!");
  lcd.setCursor(0, 1);
  lcd.print("H:"); 
  lcd.print(head_base_line);
  lcd.print("cm C:"); 
  lcd.print(chest_base_line); 
  lcd.print("cm");
  tone(BUZZER_PIN, TONE, 100);

  delay(2000);
  lcd.clear();
}

String computeState() {
  int tol = (toleranceDistance > 0) ? toleranceDistance : 6;

  bool headOutFrame  = local_head_distance  > (head_base_line  + OUT_FRAME_MARGIN);
  bool chestOutFrame = local_chest_distance > (chest_base_line + OUT_FRAME_MARGIN);

  bool headNormal  = abs(local_head_distance  - head_base_line)  <= tol;
  bool chestNormal = abs(local_chest_distance - chest_base_line) <= tol;

  bool headNear  = local_head_distance  < (head_base_line  - tol);
  bool chestNear = local_chest_distance < (chest_base_line - tol);

  bool headFar   = local_head_distance  > (head_base_line  + tol);
  bool chestFar  = local_chest_distance > (chest_base_line + tol);

  if (headOutFrame && chestOutFrame)        return "NOT SITTING";
  if (headNormal && chestNormal)            return "UPRIGHT";
  if (headNear && chestNear)                return "TOO CLOSE";
  if (headFar && chestFar)                  return "TOO FAR";
  if (headNear && chestNormal)              return "HEAD FORWARD";
  if (chestFar && (headNormal || headNear)) return "SLIDE / SLUMP";
  return "UNBALANCED";
}

void classifyPosture() {
  String raw = computeState();

  if (raw == postureState) {          // stable
    candidateCount = 0;
    candidateState = "";
  } else if (raw == candidateState) { // same new state again
    if (++candidateCount >= STATE_CONFIRM) {
      postureState = raw;
      candidateCount = 0;
      candidateState = "";
    }
  } else {                            // different state, start counting
    candidateState = raw;
    candidateCount = 1;
  }
}

void displayLocalFeedback() {
  static unsigned long lastBeepTime = 0;
  // row 1: head and chest distance
  lcd.setCursor(0, 0);
  lcd.print("H:");
  lcd.print(local_head_distance);
  lcd.print("cm  ");
  lcd.setCursor(8, 0);
  lcd.print("C:");
  lcd.print(local_chest_distance);
  lcd.print("cm   ");

  // row 2: posture
  lcd.setCursor(0, 1);
  lcd.print(postureState);
  for (int i = postureState.length(); i < 16; i++) {
    lcd.print(" "); // clear old String
  }

  // RGB and passive buzzer control
  if (postureState == "UPRIGHT") {
    setColor(0, 255, 0); // green
    isBadPosture = false;
  } 
  else if (postureState == "NOT SITTING") {
    setColor(0, 0, 255); // blue
    isBadPosture = false;
  } 
  else { // else is bad posture: (Too Close, Too Far, Head Forward, Slide)
    if (!isBadPosture) {
      badPostureStartTime = millis();
      isBadPosture = true;
    }

    unsigned long badDuration = millis() - badPostureStartTime;
    if (badDuration < ALERT_DELAY) {
      setColor(255, 180, 0); // 1st warning: yellow RGB, no Buzzer
    } else {
      setColor(255, 0, 0);   // 2nd warning: red RGB, Buzzer sound
      if (millis() - lastBeepTime >= 1000) {
        lastBeepTime = millis();
        tone(BUZZER_PIN, TONE, 50);
      }
    }
  }
}

void onCalibrateTriggerChange()  {
  if (calibrateTrigger) {
    calibrateRequested = true;
  }
}

void onToleranceDistanceChange()  {
  Serial.print("New Tolerance from Cloud: +/- ");
  Serial.print(toleranceDistance);
  Serial.println(" cm");
}
